# NumPy

↑ [[00-Mapa]] · Archivo: [numpy.ipynb](../../numpy.ipynb)

Arreglos y matrices básicas con `import numpy as np`.

## Qué se hace
1. `np.arange(1, 11)` — arreglo del 1 al 10.
2. `arr.max()`, `arr.min()` — métodos del arreglo.
3. `np.zeros(5)`, `np.ones(5)` — arreglos de ceros y unos.
4. `np.array([[1, 2, 3], [4, 5, 6]])` — matriz 2×3.
5. `matrix.shape` → `(2, 3)` (filas, columnas).

## Conexiones
- Se construye a partir de [[Listas]] anidadas.
- `max/min` como funciones en [[Listas]] y [[Tuplas]], como métodos aquí.
