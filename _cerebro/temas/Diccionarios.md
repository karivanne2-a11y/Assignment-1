# Diccionarios

↑ [[00-Mapa]] · Archivo: [dictionaries.ipynb](../../dictionaries.ipynb)

Ejercicios con `population` (Lima, Arequipa, Trujillo).

## Qué se hace
1. Crear el diccionario llave → valor (ciudad → población).
2. `keys()` — solo las llaves.
3. `get("Lima")` — busca por llave; devuelve `None` si no existe (no lanza error, a diferencia de `population["X"]`).
4. `population["Cusco"] = 428000` — agregar una entrada.
5. `pop("Trujillo")` — elimina y devuelve el valor.
6. Resultado final: Lima, Arequipa y Cusco.
